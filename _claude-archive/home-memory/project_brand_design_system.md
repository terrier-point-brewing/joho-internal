**Brand & design system for the brewery.** Joho = the brewery brand; TPB (Terrier Point Brewing) = legal entity. Goal: hold Joho's brand as a single versioned, in-app-editable source of truth that both internal surfaces and future customer-facing/AI features (marketing, apparel, physical labels) consume.

Source brand guide = "Joho Brand Guide v1.0" (Claude artifact `ed996d69-c19a-430f-abfd-80b376e7c6b4`, self-described "Placeholder · non-final"), written for humans + agents with Narrative + Specification layers (Specification governs). Joho canon: mission "Beer is the medium, not the mission"; Tier 1 colors Paper `#f5f0e6` (60%), Indigo `#26355d` (30%), Seal Red `#ad1a2d` (≤5%), Camphor Tan `#b3a585`; fonts Marcellus (display) / Lato (body) / Jost (interim wordmark) / Noto Serif SC; per-label Tier 2 palettes; chop seal; fixed label "chassis".

**Locked architecture (see `docs/superpowers/specs/2026-07-19-brand-design-system-design.md`):**
- Three-level indirection: **canon (DB, editable) → semantic role contract (code, stable) → resolver → 3 outputs**. Consumers bind to `--color-brand-primary` / `text-brand-high-contrast` / `font-brand-display` — NEVER brand/color names, so Joho→Tanka or Indigo→Cobalt is a one-row canon edit.
- **Two design systems stay separate:** ops chrome `--color-*` (dark zinc/amber, code-owned in globals.css, UI_STANDARD-governed) is untouched; brand `--color-brand-*` is a new namespace, DB-driven, opt-in via `.brand-surface` scope. Brand editor governs `--color-brand-*` only.
- Dark mode **auto-derives from light** (brand-hued: dark bg borrows primary hue), editable after via sparse `roleMap.dark` overrides in canon.
- Storage: **Supabase-backed, in-app editable, versioned**. Hybrid schema — canon = versioned JSONB document (`brand_canon_versions`, one published row); catalog (assets/labels) = normalized tables added per phase. NO `is_placeholder` (founder is sole canon editor, holds it in head). `brand_assets` lean (~10 cols); `label_id`/`motif_family` added Phase 3, `source`/`generator_meta` added Phase 4. `brand_labels.tier2_palette` embedded jsonb.
- Resolver `lib/brand/`: outputs = design tokens (CSS vars via runtime-injected `<BrandStyle>`), compiled agent brief (for AI features), resolved assets.
- Phases: **0 foundation (this plan)** → 1 canon editor + guide viewer → 2 asset library → 3 labels+Tier2 → 4 AI studio → 5 public surface. Each = own spec→plan cycle.
